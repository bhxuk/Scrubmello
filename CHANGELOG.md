# Changelog

Every change to the Scrubmello website, newest first.

---

## [0.2.0] - 2026-11-01
**Request:** Redesign in the style of Halcyon Lighting (Awwwards), with well developed products and the best possible product images. Handles about an inch or less wide, varying, soft feel, see-through in places. Also make a GitHub landing page.
### Added
- Full 3D models of the range (`design/sm.py`, Blender): 4 slim handles (13 to 25mm wide) in soft-touch silicone with clear frosted parts, 8 egg-shaped heads, the Mello Click collar, suction and screw hooks.
- Photoreal product renders in `public/img/`: hero line-up, every handle, every head, colourways, all four sets, the click system and the hooks.
- Day and night mode, remembered per browser.
- Scroll effects: statement text that lights up word by word, sticky system image, fade-in reveals.
- Materials section and real sizes on every product.
- README rebuilt as a landing page with the renders, so the GitHub repo page works as a showcase.
### Changed
- Whole site redesigned: minimal and type-led, large light headings with serif accents, thin rules, numbered sections, giant footer wordmark. Still soft pastels.
- Colours renamed (Blush, Sky, Butter, Charcoal, Cloud, Rainbow) and Mint and Lilac added. The Intimate head is always Lilac.
### Removed
- The drawn mix-and-match builder (replaced by the real renders).

## [0.1.0] - 2026-11-01
**Request:** Set up a base landing page for the Scrubmello brand, similar to the Pepper Gardens site. Theme: relaxed and modern with soft pastel colours.
### Added
- Home page with hero, How it works (the Mello Click system), Build yours, Handles, Heads, Colours, Sets, Made for every body, FAQ and a launch list sign-up.
- Product list in `data.js`: 4 handles, 8 heads, 6 colours, 4 sets. All prices show "Price coming soon" until set.
- Placeholder product drawings in code: egg-shaped heads with different textures, four handle styles.
- Build yours tool: pick a handle, head, head colour and handle colour and see it drawn.
- GitHub Pages preview workflow.
